## Default Permission

Default permissions for add-to-calendar plugin

#### This default permission set includes the following:

- `allow-add-event`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`add-to-calendar:allow-add-event`

</td>
<td>

Enables the add_event command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`add-to-calendar:deny-add-event`

</td>

</td>
</tr>
